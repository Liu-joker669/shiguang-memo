# 拾光 Memo（Shiguang Memo）

面向大学生考前复习场景的可交互 Web Demo。产品尝试把分散的课程资料串成一条可核对的复习闭环：导入资料、生成复习要点、完成诊断、回看薄弱来源，再通过资料问答定位内容。

> 当前阶段：本地规则 Demo。项目不调用大模型，也没有实现真正的 RAG、PDF 解析或向量数据库；界面中的总结、诊断和问答用于验证产品流程与异常边界。

**在线体验：** [https://liu-joker669.github.io/shiguang-memo/](https://liu-joker669.github.io/shiguang-memo/)

## 核心闭环

`导入课程文本 → 自动整理复习要点 → 完成诊断测验 → 定位待回看资料 → 带来源进行问答`

## 已实现

- 课程文本导入，并在浏览器 `localStorage` 中持久化；
- 基于文本结构的本地摘要和要点提取规则；
- 资料库、资料详情、知识卡片、诊断测验和问答共享同一份数据；
- 根据资料要点生成诊断题，展示得分并跳回答错题目的来源；
- 支持中文问题关键词检索、无结果提示和来源资料跳转；
- 内置示例资料重置，方便重复体验；
- 6 项自动化测试覆盖文本导入、中文检索、来源返回和诊断规则；
- 响应式移动端界面与 GitHub Pages 基础路径支持。

## 功能边界

| 能力 | 当前实现 | 边界 |
|---|---|---|
| 资料导入 | 粘贴纯文本 | 不解析 PDF、Word 或图片 |
| 自动整理 | 本地文本规则 | 不是 LLM 总结 |
| 资料问答 | 关键词检索 + 固定模板 | 不是真实 RAG，不生成开放答案 |
| 来源追溯 | 跳回本地资料 | 没有页码级引用 |
| 诊断测验 | 根据资料要点生成规则题 | 结果不代表真实知识掌握度 |
| 数据存储 | 当前浏览器本地存储 | 无账号、云同步和多人协作 |

真实用户访谈、可用性测试、检索准确率、学习效果和留存数据尚未完成，不能作为已有成果描述。

## 产品取舍

- 将宽泛的“个人知识管理”收敛到大学生考前课程复习；
- 优先验证“诊断后能否快速回到原资料”，而不是堆叠生成式功能；
- 用本地规则替代真实大模型，降低部署成本并明确演示边界；
- 无检索结果时拒绝拼接答案，避免把不存在的内容包装成知识库结论；
- 后续只有在真实任务测试证明流程有价值后，才考虑 PDF 解析、向量检索和 LLM 接入。

更完整的范围说明见 [产品说明与决策记录](docs/product-brief.md)。
